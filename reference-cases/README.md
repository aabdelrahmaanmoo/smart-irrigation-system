# الحالات المرجعية

> حالات حسابية بنتيجتها الصحيحة من مرجع معتمد. الاختبارات الآلية بتقرا الملفات دي وتقارن نتيجة المحرك بيها.

## مين بيضيف حالة

- **المهندس** يضيف الحالة من دليل الفاو أو `CROPWAT` أو حساب يدوي مراجع.
- **المبرمج** مابيعدلش القيم. لو الاختبار فشل، المشكلة في الكود أو في الحالة، والمهندس يراجع.

## شكل الملف

> **مقترح:** ملف `csv` لكل نوع حساب، وكل سطر حالة.

| العمود | معناه |
|---|---|
| `case_id` | رقم الحالة |
| `description` | وصف قصير بالعربي |
| `inputs...` | أعمدة المدخلات بوحداتها في اسم العمود |
| `expected...` | أعمدة النتيجة المتوقعة |
| `tolerance` | الفرق المسموح |
| `source` | المرجع ورقم الصفحة أو المثال |
